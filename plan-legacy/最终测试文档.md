## 一、测试总纲与承诺映射

### 1.1 总纲七条（架构裁定）

1. **分层轴＝判官介入深度×失败定位半径**（非代码粒度）。五层：L-U 纯逻辑（无浏览器/LLM/网络，全量 <30s）→ L-I 单浏览器趟（金标+变异，单件 <60s、全量 <10min）→ L-E 全管线 cassette（30–60min）→ L-B 批跑（分布证据唯一产地，他层只产通过/不通过）；**holdout 在金字塔外**（验收协议，非「更大 E2E」），运行器不入主仓构建目标，防「跑通全塔」式触碰。失败定位半径逐级对应：改纯函数→CHK 编号/kernel→七模块（F 类 stage 字段）→里程碑回滚。
2. **退出码三值、判定态四值、批级元判定三级分离**。退出码 0 绿/1 红/2 用法错（含环境缺失）给 shell 与门禁链；判定态 pass/fail/skip/TIMEOUT 给报告与统计（TIMEOUT 报 exit 1 但单列桶）；skip>10% 整批不采信等批级判定**只能由独立 gate-aggregator 下**（只读留档 JSON 独立重算＋横幅对账；子门 status null 必红），不由产出报告的进程自下。
3. **采集-判定分离升格**：一条 facts 采集管线按级切判定切片（qacore 采集/判定分离结构的延续）；上级未过时下级输出 **blocked**（未达判定前提）而非 fail——「没测到」≠「测了不过」，是 F3/F4/F5 落位前提。
4. **环境自检是第 0 项门禁，红路断言以其通过为生效前提**。T4 实测：cli.mjs:15 静态 import（顶层 import playwright），环境损坏时参数解析发生在模块图加载后，好/坏输入同为 exit 1、exit 2 通道消失。裁定：缺依赖→exit 2 不冒充代码红（ENV-01）；**红路判定＝环境自检 exit 0 ∧ 实测退出码＝期望码 ∧ 诊断＝期望 F 类**，环境未过时红路结果记 ENV_ERROR 不作数（E-04 前置条件）；M0 改造 CLI 参数解析与重依赖 import 解耦（ENV-03）。
5. **判官三档分档统计严禁合并**。judge_drive_tier 为报告一等公民字段；档位由输入来源在代码层硬绑定：我方产物＝档 1 白盒钩子，外部输入/oracle/holdout＝档 2 探针或档 3 黑盒，外部输入路径注入 `__PF_QC__` 的调用直接抛错（证据 checks.ts:190-192：无钩子即 fail，注入即全绿＝判官同谋）。
6. **凡能机检绝不交 LLM**；人眼只允许在 L3 盲评抽检位（登记不设门）；不可自动化项显式标「人工」并给记录格式（1.3）。
7. **留档纪律**：runs/ 白名单首日放行、只追加、报告机生非手维护；报告分**内容域**（判定/事实/指标，零时间戳零随机序，进哈希、进差分）与**封装域**（时间/机器/git commit/耗时，侧车 manifest，不进任何哈希）；每趟判官先清本趟目标报告路径、跑完断言存在且非空（幽灵文件防护）。T5 实锤 run.ts:377 临时端口与 assemble-report.mjs:169 generatedAt 已破坏字节复算——列 M0 改造项（I-08）。

## 三、holdout 验收（独立章节，13 条）

**隔离原则**：holdout 退化主因不是样本少，是「被看见过」——抽样式建集、约定式隔离、判官自报三事同发。三层分账：dev 集（开发可见，日常回归与变异构造）／seal 集（分布公开、条目不可见——可问「A5 家族条件通过率」，不可问「验收用哪三款」；族覆盖须显著宽于 dev 防反推）／private 集（验收人持有条目本体）。物理隔离三层：路径（条目在独立凭据后端仓——peidian「不在本仓库内」体例）＋凭据（开发机只有提交产物/取回报告入口）＋流程（解封需 owner 动作；seal 登记提交号＋清单/判官 sha256＋环境指纹；新仓 git init 与 commit 绑定）。

**验收集构成与冻结**：最低 ≥30 条（规划 M3 口径）含 ≥20% 坏输入，推荐 ≥60（owner 拍板项⑪）；按（超类×输入形态 T1/T3）分层，族级下限 1、超类级下限 4；C/E 超类只放已支持族或标「本轮不可达、留待 v1.5」，不稀释分母；抽样在 seal 之后由验收侧执行（**抽样器与数据集分离**，规则只约束配额不定款式）；冻结三件套＝datasetVersion＋set_sha256（条目名+sha256 排序串哈希前 16 位，golden_set_version 体例）＋LOCK；is_holdout/first_seen_at 由验收侧在冻结后维护；holdout seal 与 oracle seal 为**两份独立 seal**（同机制）；oracle 语料禁入 holdout（无需隔离的对齐对象，充数即失效）。算力推算 ≥60×5×4 渠道 ≈6.3 小时（19.2s/格实测）——不进日常 CI，owner 在场低频事件；超预算**砍渠道保轮次**（砍轮次毁尾部这个唯一对外承诺量）。

**判官独立性协议**：①档位硬绑定（输入来源决定，代码层拒绝越档，HT-04 复验）；②判官四组指纹登记 seal：判定层（checks/run/autoplay＋**probe.ts**——探针不在冻结清单却改判定语义，09-30 实改过）／规则层（channel-rules.json）／阈值层（invariants.ts）／环境（node/chromium/playwright 版本＋机器类）；③报告两层化＋verdict_body 可被第三方复算（复核器只用标准库、不 import 被审模块）；④可见性刻意不对称：可见＝分桶条件通过率/尾部/方差/F1–F9 计数/判官指纹/变异覆盖率/错误拒绝条数；不可见＝逐样本明细/失败样本身份/特征串与分项 sha/变异样本本体/错误接受具体样本（只给总数与族分布）——误杀要修必须能定位，错误接受是红线定位权留验收人。

**红路清单（holdout 坏输入五类分层报率）**：畸形描述／空输入／超大输入／非游戏输入（文本/HTML/视频）／分类学外（含 T5 APK）。**反作弊机检清单（统一族，T2/T5 分工见 D1）**：假可玩（I-11 判据族＋MUT-00/03/05/06 恰命中）／幻觉功能（F0 差集非空→F6，holdout 内按 fail 计保守侧）／超时降级（TIMEOUT 第三态单列）。

## 四、统计与回归方案

**批跑设计**：三层节奏（快速回归 3 渠道×30×1 轮日跑；周跑 4 协议类代表；release 全 7×R=5）；jobs 固定 2 不自适应（jobs=4 实测把 CHK09 2.0s 顶破至 3.4–8.4s；jobs 是协变量，跨轮比较必须同值）；时序敏感断言（首含义交互 ≤5s 等）留**串行槽**或空载基线对照，并行浏览器污染时序判据是假红源；加载类指标采中位数（+2 趟加载）。

**承诺桶与观测桶**：26 族×4 形态×7 渠道＝728 理论桶，逐桶检验族系误差≈1 什么都证不出；仅 owner 冻结的承诺桶（T1/T3/T-mid）带下界，其余观测桶只报计数/翻转率/F 类分布；观测桶晋级承诺桶＝连续 K 轮样本量足够＋责任人签字（防事后挑桶）。试验单位是**输入**不是试次：同输入 R 轮是区组非独立样本；桶级报 mean(p_i)/min(p_i)/p_i<1 占比三件套。

**三把尺子**：承诺＝Clopper–Pearson 单侧 95%（零失败 n=59→0.9505；承诺值须显著高于运行点才可证——实测恰在 70% 则「≥70%」不可证，n=30 需实测 ≥26/30）；报告给人看＝Wilson 区间；回归比较＝配对 exact McNemar。零翻转上界＝1−0.05^(1/n)，与零失败同成本——「成功率高」与「判定稳定」各需 59 次无例外。第 5 量（判官自一致）由 E-09 金丝雀承载（QC-02 曾 43/48 格假失败，判官自扰非产物缺陷）——**先证量具稳再测被测物**。

**回归漂移判据**：三层摘要（ST-02）；每轮变更跑 benchmark 全集回归；换引擎/换素材/改构建参数后变异覆盖必重跑（脱敏教训）；`.gitattributes * -text` 有专项断言（U-06，跨平台字节静默漂移最便宜的回归门）。

## 五、输入集与 oracle 库管理测试

判据落点在 AS-01~13，此处补机制说明。**版本化**：三件套（语义化版本＋内容寻址＋LOCK），LOCK 失配 exit 2 非 1；变更单调剂把「随手改一下」变成必须解释的动作。**防静默劣化三机制**：①分位数与集合绑死（AS-09，防「M3 的尺子悄悄换了 M4 还绿」）；②超龄分级（AS-08，采集日期分层要有执行力）；③evidence 机制从渠道规则原样搬到 oracle 条目（同机制解两类漂移，不另发明）。**活性四态**：ALIVE_UNCHANGED／ALIVE_CHANGED（200＋sha 变＋运行器仍出双组流→变更单重标重跑分位）／DEAD（retired 剔除分位不删记录）／GONE_BY_POLICY；HTTP 200 恰是最危险状态（换游戏/错误页都 200），语义级复验唯一能识别。**skip 累积报警**：网络不可得→SKIP-ENV 计入并报告，连续 N 次本身报警（防常年断网机器拿全 STALE 绿灯）。**出网约束**：采集器出网与判官本地伺服（127.0.0.1＋端口白名单）两条路径分开校验。**canary 手法**为通用范式：任何「不许把 X 送进 Y」的流程承诺降维成「标记串零出现」的可回归字符串断言。
